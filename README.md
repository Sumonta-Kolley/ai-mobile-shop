## 📝 Description
An interactive, AI-powered mobile store management dashboard. Built entirely with Python and Gradio, this lightweight application uses lists and dictionaries for data storage. It integrates **Google's Gemini AI** to act as a virtual store assistant—providing smart phone recommendations, detailed side-by-side comparisons, and answering user queries based strictly on the shop's current inventory.

## ✨ Features
* **📋 Inventory Management:** View, add, delete, and purchase mobile stock in real-time.
* **🔍 Search & Budget Filters:** Easily find phones by brand, model, or maximum budget.
* **📈 Shop Statistics:** Automatically calculates total models, stock levels, average pricing, and identifies the highest-rated phone.
* **🤖 Gemini AI Assistant:** Ask custom questions about the inventory (e.g., "Which phone has the best battery under ₹50,000?").
* **🎯 AI Recommendations:** Enter a budget and use-case (e.g., Gaming, Study) to get a personalized, AI-generated phone suggestion.
* **⚖️ AI Comparison:** Get a detailed head-to-head analysis between any two phones in the store.
